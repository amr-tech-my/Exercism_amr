## About PowerShell
PowerShell is an open-source, cross-platform scripting language, shell, and configuration management framework built on .NET. It enables automation of tasks across operating systems, data centers, and cloud environments. Unlike traditional shells, PowerShell passes **objects** through its pipeline, allowing structured data such as JSON, XML, and CSV to be manipulated directly without text parsing.

### Key Features
- Object-oriented pipelines for structured data.
- Extensible via scripts, functions, cmdlets, and modules.
- Unified management of file systems, registries, databases, and cloud resources.
- Built-in cmdlets for processes, services, logs, web requests, and more.
- Full .NET integration with access to external libraries from NuGet.
- Cross-platform support for Windows, Linux, and macOS.
